# Trick Map

Map your flatground skate tricks. Every trick is an ollie plus ingredients (shoves, flips, body spins), split into Sun, Earth and Moon sides.

- Map view: drag orbs, hover (PC) or hold (phone) to set a level, tap to open the breakdown and foot positions
- Stance grid: regular, fakie, switch and nollie for every trick
- Everything saves on the device you use. No account needed.

## Install on your phone
Open the site in Safari, tap Share, then Add to Home Screen.

## Run it
It's a static site: `index.html`, `manifest.webmanifest`, `sw.js` and `icons/`. Deploy the repo on Vercel with no build settings.
